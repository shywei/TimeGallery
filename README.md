# 拾光记 (TimeGallery) · 时光画册与岁月档案

> 私有化家庭时光画册与岁月数字档案系统 (Windows 10 / 11)  
> 🔗 开源主页：[https://github.com/shywei/TimeGallery](https://github.com/shywei/TimeGallery)

---

## 🌟 产品核心理念

**所有照片都值得被保存，但不是所有照片都需要以同样的方式被观看。**

**拾光记** 是一套以时间为主线的私有化数字画册系统。它不仅适用于长期记录孩子的成长，也完美契合家庭生活、情侣恋爱、旅行足迹与人生重要里程碑的长期沉淀：

- **完整每日档案（Daily Archive）**：严格归档每日日常主图（`yymmdd.jpg`），提供日视图、周视图、标准月历、瀑布流月度照片墙与倒序时光河流。
- **特别时刻回忆（Special Moments）**：对生日、纪念日、旅行或重要庆典，通过专属日期文件夹（`yymmdd/`）容纳不定张数的照片与高清视频，提供视频关键帧提取与画廊浏览。
- **精选珍藏展示（Highlights）**：人工标星挑选值得特别展示的闪亮回忆，添加心语手记、标签与专属主题合集。
- **时间回响回顾（Memories）**：首页摄影杂志化呈现“历史上的今天”、“往年此时”与每日“随机回忆”。

---

## 🌟 核心功能亮点

1. **日常浏览与后台维护清晰分权**：
   - **浏览模式（日常使用）**：涵盖照片与视频浏览、日历与时间线查看、心语修改、标星精选、打标签，以及主题合集的新建、编辑与照片整理。
   - **管理模式（后台维护）**：专注系统级运维，包括**档案内容维护（主图/时刻手动补录与回收站）**、磁盘扫描器、异常排查诊断、基准类型设置与数据库快照备份。
2. **档案内容维护与时间戳版本化回收站（.trash/）**：
   - 支持在后台直接上传、覆盖替换或删除任意日期的主图与特别时刻。
   - **绝对防误删**：所有被替换或删除的文件自动附加精确到秒的时间戳移入隐藏回收站（`.trash/`），多次删除同一天零冲突，随时可查可撤回，并支持一键彻底清空。
3. **特别时刻多媒体图集**：
   - 识别 `photo_root/yymmdd/` 目录下的多张照片与高清视频。
   - 自动提取视频代表帧生成缩略图，在日历与日视图上带有特别标记，支持自定义时刻标题与故事手记。
4. **主题合集无限滚动翻页与后端检索**：
   - 合集照片选择器采用分页无限滚动加载（Scroll-to-Load-More），单页按需加载 40 张，杜绝大量照片卡顿。
   - 支持按年份切片与关键词模糊检索，全部由后端 SQL 高性能实时过滤，选中的照片跨页跨搜索保持记忆。
5. **灵活的基准日期体系**：
   - 支持**生日**（精准计算各时期年龄）、**纪念日**（结婚/恋爱周年）、**起始日**（创业/旅行天数）、**自定义里程碑**或**暂不设置**。
6. **固定顶栏与 0 毫秒懒加载架构**：
   - 顶部导航栏与主体滚动区分离，彻底消除页面滚动带来的视觉抖动；采用后台常驻（Keep-Alive）机制，页面切换即时呈现。

## 🔒 核心数据安全与规则保证

1. **严格规范命名**：
   - 每日主图严格采用六位数字 `yymmdd.jpg`（如 `241103.jpg` 代表 2024年11月03日），年份固定按照 21 世纪计算（2000～2099）。
   - 特别时刻严格采用六位数字子文件夹 `yymmdd/`，支持存放不定张数的照片与常见格式视频。
2. **回收站隔离防护**：
   - 手动替换或删除产生的文件均移入 `.trash/` 隐藏目录，现有的自动扫描器天然过滤隐藏目录，绝不会被误扫回相册。
3. **扫描保护已有数据**：
   - 全量重新扫描根据唯一日期记录绑定，绝不丢失用户已编辑的照片心语、标签、精选标记与合集关系。
4. **数据物理隔离**：
   - 缩略图（480px WebP）、高清预览图（1600px WebP）、SQLite 数据库、日志与备份统一存储在独立 `data/` 目录中。
5. **单端口运行**：
   - 生产模式下由 FastAPI 统一托管后端接口与前端静态资源（默认端口 8765），局域网内任意手机、平板、电脑均可直接访问。

## 🚀 快速启动说明 (Windows)

### 方式一：一键启动 (推荐)

直接双击运行根目录下的：
```bat
run.bat
```
`run.bat` 将自动检查 Python 环境，检查前端静态编译资源（若无则自动编译），并启动单端口服务。

启动后在浏览器打开：
```text
http://127.0.0.1:8765
```

### 方式二：命令行服务管理

- **启动服务**：`scripts\start.bat`
- **停止服务**：`scripts\stop.bat`（根据 8765 端口精准终止服务进程，不误杀其他 Python 进程）
- **编译前端**：`scripts\build.bat`
- **备份数据库**：`scripts\backup.bat`
- **环境检查**：`scripts\check_environment.bat`
