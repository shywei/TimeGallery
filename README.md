# Growing Up · 时光档案

> 家庭私有化儿童成长照片档案与数字化展示系统 (Windows 10 / 11)

---

## 🌟 产品核心理念

**所有照片都值得被保存，但不是所有照片都需要以同样的方式被观看。**

Growing Up 是一个以时间为主线的数字成长档案系统，专为长期记录孩子的日常生活而设计。

- **完整档案层（Archive）**：严格归档每日日常照片，提供日、周、标准月历、月度照片墙与连续时光河流。
- **精选展示层（Highlights）**：人工挑选值得特别展示的闪亮回忆，添加心语、描述与自定义标签。
- **时间回顾层（Memories）**：首页摄影杂志化呈现“历史上的今天”、“去年此时”与稳定“随机回忆”。

---

## 🌟 产品核心功能亮点

1. **固定顶栏与丝滑无抖动体验**：顶部导航栏与主体滚动区分离，切换标签页采用按需懒加载与后台常驻（Keep-Alive）架构，切换达到 0 毫秒即时呈现，无白屏加载与滚动条晃动。
2. **日历与时间全景档案**：支持输入 `2024-11-03` 或 `241103` 瞬间定位，日历年月标题采用定宽与等宽数字防误触设计；提供日、周、标准月历、月度瀑布流照片墙与倒序时间河流。
3. **就地档案直接编辑**：照片心语与故事直接在输入框修改，支持快捷键 `Ctrl+Enter` 保存；标签支持气泡增删与历史推荐快捷打标；支持直接归入或移出主题合集。
4. **历史上的今天微缩画廊**：在详情弹窗内自动列出往年同一天拍摄的所有历史缩略图与当时年龄，一键穿梭回顾那一年的今天。
5. **全屏沉浸浏览**：支持键盘方向键（`←` / `→`）双向连续穿梭前一日与后一日照片，在全屏模式下同样支持一键设置精选。

---

## 🔒 核心数据安全与规则保证

1. **绝对只读原始照片**：系统绝不修改、不压缩、不重命名、不移动、不删除用户原始照片。
2. **严格日期命名**：原始照片文件名必须为严格六位数字 `yymmdd.jpg`（如 `241103.jpg` 代表 2024年11月03日），年份固定按照 21 世纪计算（2000～2099）。
3. **每日一张照片**：每个自然日最多归档一张有效照片；若在不同子目录下发现同日期的冲突照片，系统**严禁自动覆盖或删除**，而是记录为 `DATE_CONFLICT` 冲突异常供管理员核验。
4. **全量扫描安全机制**：全量重新扫描绝不清除已编辑的照片心语、标签、精选标记与合集关系；若用户替换了原图，系统将自动比对文件更新缩略图与高清缓存。
5. **数据物理隔离**：缩略图（480px WebP）、高清预览图（1600px WebP）、SQLite 数据库、日志与备份统一存储在独立 `data/` 目录中。
6. **单端口运行**：生产模式下由 FastAPI 统一提供服务（默认端口 8765），前后端通过单一端口即可在局域网内任意浏览器访问。

## 🚀 快速启动说明 (Windows)

### 方式一：一键启动 (推荐)

直接双击运行根目录下的：
```bat
run.bat
```
`run.bat` 将自动检查 Python 环境，检查前端静态编译资源（若无则自动编译），并启动单端口服务。

启动后在浏览器打开：
```text
http://127.0.0.1:8765
```

### 方式二：命令行服务管理

- **启动服务**：`scripts\start.bat`
- **停止服务**：`scripts\stop.bat`（根据 8765 端口精准终止服务进程，不误杀其他 Python 进程）
- **编译前端**：`scripts\build.bat`
- **备份数据库**：`scripts\backup.bat`
- **环境检查**：`scripts\check_environment.bat`
