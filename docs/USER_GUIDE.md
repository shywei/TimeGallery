# 拾光记 (Shiguangji) · 用户使用手册

拾光记是一套专为记录家庭美好岁月打造的私有化、轻量级、摄影杂志质感的时光画册与数字档案系统。无论是孩子的成长足迹、伴侣的恋爱结婚纪念、每一次远行旅途，还是人生的重要里程碑，都能在此温雅安放。

---

## 1. 首次使用向导 (Setup Wizard)

首次运行应用并在浏览器打开 `http://127.0.0.1:8765` 时，系统将引导您完成初次初始化配置：

1. **设置基准日期类型与基准日**：
   - **生日 (Birthday)**：适合记录孩子成长或个人生辰，系统将自动精确计算每张历史照片拍摄时的具体年龄（如 `2岁10个月3天`）。
   - **纪念日 (Anniversary)**：适合记录结婚、恋爱等重要纪念，自动计算“第 X 周年第 Y 天”。
   - **起始日 (Start Date)**：适合记录创业、搬入新居、开始新生活等，自动计算“第 X 天”。
   - **自定义里程碑 (Custom)**：允许自定义标签名称与基准日期。
   - **暂不设置 (None)**：作为纯粹的通用家庭时光相册使用，不显示年龄/天数后缀。
2. **设置照片存储根目录**（例如 `D:\photos`）：指定存放 `yymmdd.jpg` 每日主图及 `yymmdd/` 特别时刻文件夹的本地目录。
3. 点击“完成初始化”，系统将自动触发初次全量索引，并在后台秒级生成 WebP 缩略图与高清预览图。

## 2. 浏览模式与管理模式的分工

拾光记将**日常相册欣赏**与**后台运维维护**进行了清晰的权责划分：

### 2.1 浏览模式 (日常使用)
- 导航包含：**首页**、**日历档案**、**时光河流**、**珍藏精选**、**主题合集**、**特别时刻**。
- 支持在日常浏览过程中随时：
  - 新建、修改、删除主题合集，挑选照片归入或移出合集；
  - 浏览特别时刻的照片与视频，就地修改特别时刻的标题与故事手记；
  - 修改单张照片的心语故事、标星精选、增删标签。

### 2.2 管理模式 (后台维护)
- 点击顶部右上角的 **“浏览模式 / 管理模式”** 切换按钮，输入或确认进入管理模式。
- 导航栏将展示专属的 **“后台维护”** 入口，包含 5 大专业维护模块：
  1. **档案内容维护**：支持任意日期的主图/特别时刻的手动上传、覆盖替换、删除及回收站管理；
  2. **照片扫描器**：触发全量扫描或增量扫描，查看缺失日期报告并支持一键跳转补录；
  3. **扫描异常排查**：诊断无效文件名、重复内容或日期冲突异常；
  4. **系统配置**：随时调整基准类型、基准日期、自定义标签与照片库根目录；
  5. **数据备份与恢复**：生成 SQLite 数据库快照、恢复历史版本或导出归档 JSON。

## 3. 核心功能浏览指南

### 3.1 首页 · 摄影杂志 (Home)
- **岁月回响 · 历史上的今天**：核心视觉展台，展示往年同日的经典瞬间，支持 8 秒平滑自动轮播，悬停自动暂停。
- **岁月里程碑与统计**：直观展示已归档有效照片总数、已记录自然日天数及当前基准阶段。
- **近期瞬间**：倒序呈现最近归档的 7 个自然日主图，快速概览近况。
- **珍藏精选预览**：横向排布人工挑选并标星的精彩瞬间。
- **档案导航中心**：提供通往各个维度的快捷导航卡片。

### 3.2 日历档案 (Calendar)
- **多维度检索与定位**：
  - **快捷输入跳转**：直接在顶栏输入 `2024-11-03` 或 6 位 `241103`，回车即可瞬间定位。
  - **日期防抖翻页**：年月标题区域拥有固定宽度与等宽数字（`tabular-nums`），快速点击翻页箭头不会发生位移。
- **四大时间视图**：
  - **日视图 (Day View)**：呈现当天高清大图、完整拍摄日期、心语故事；若这一天包含**特别时刻图集**，日视图将展示醒目的“特别时刻”卡片入口，点击可直接打开图集画廊。
  - **周视图 (Week View)**：周一至周日 7 天矩阵，展示本周记录密度。
  - **标准月历 (Month View)**：标准 7 列日历，有特别时刻的日期带有闪亮星标标记。
  - **月度照片墙 (Photo Wall)**：瀑布流按日期升序排列当月所有照片，完整呈现当月生活卷轴。

### 3.3 特别时刻 (Moments)
- 独立展示所有包含**多张照片与高清视频**的特殊日子（对应目录 `photo_root/yymmdd/`）。
- **时光画廊弹窗**：
  - 支持多图平铺与幻灯片式大图放映；
  - 视频支持在线直接流畅播放与音量控制；
  - 支持在弹窗内直接点击铅笔图标编辑特别时刻的**专属标题**（如“三周岁生日庆典”）与**故事心语**，即时保存。

### 3.4 主题合集 (Collections)
- **自由创建专属故事合集**：如“第一次旅行”、“海滨度假”、“毕业纪事”等专属画册。
- **无限滚动翻页（Infinite Scroll）**：
  - 添加照片弹窗采用分页异步加载，单页轻量拉取 40 张，向下滚动自动平滑加载下一页，相册存有数万张照片也能秒开。
- **后端实时搜索与年份切片**：
  - 支持按年份切片查看（如 `2026年`、`2025年`、`2024年`）；
  - 搜索框支持日期（`2025`、`11-04`、`241104`）及文字描述模糊搜索，所有搜索均由后端 SQL 即时处理。
- **跨页选择记忆**：切换年份、滚动翻页或搜索时，已勾选的照片在全流程中保持选中，确认时一并批量加入合集。
- **合集移出**：在合集内悬停照片点击“移出合集”，即可解除关联（不会删除相册中的照片原图）。

### 3.5 珍藏精选 (Highlights)
- 集中陈列所有打上闪亮星标的珍贵照片。
- 顶部支持按标签胶囊快速筛选，单选某标签后仅呈现打上该标签的精选照片。

## 4. 照片详情与就地快捷编辑

点击相册中任意照片缩略图均可呼出照片详情弹窗，弹窗支持**就地即点即改**：

1. **标为精选**：点击星标在“精选瞬间”与“普通归档”之间快速切换。
2. **照片故事手记**：输入框可随时直接编辑；内容变动时右上角浮现“更新故事”与“还原”按钮，支持快捷键 **`Ctrl + Enter`** 快速提交。
3. **标签分类维护**：已打标签以气泡展示，点击标签旁的 `×` 即可直接移除；点击 `+ 添加标签` 展开面板，支持输入新标签或点击推荐标签快捷打标。
4. **所属合集就地调整**：展示该照片归属的所有合集，支持一键加入新合集或移出已有合集。
5. **往年同日画廊 (On This Day)**：弹窗右侧自动检索往年同月同日拍摄的历史照片缩略图与当时年龄，点击任意缩略图即可原地切换查看那一年的今天。
6. **全屏沉浸大图**：点击“全屏”进入黑底无干扰大图模式，支持键盘方向键（`←` / `→`）平滑切图、`Esc` 退出。

## 5. 档案内容维护与安全回收站机制 (管理模式)

进入“管理模式”后，点击 **「档案内容维护」** 选项卡，即可进行人工档案干预：

### 5.1 每日主图的手动维护
- **上传主图**：若某自然日漏拍或未归档，可在日期选择器选定日期，点击【上传并归档此日主图】，系统会自动将其规范重命名为 `YYMMDD.jpg` 存入相册根目录并建立索引。
- **覆盖替换主图**：若找到了同日期更清晰的原图，点击【替换为主图】上传新图。
  - **安全备份保证**：系统绝不会直接覆盖抹除旧图，而是将旧图重命名为 `.trash/daily/YYMMDD_YYYYMMDD_HHMMSS.jpg` 移入回收站。
- **删除主图**：点击【删除主图】，原图将带有独立删除时间戳移入回收站，相册数据库解除该照片记录与合集关联。

### 5.2 特别时刻的手动维护
- **创建与批量上传**：选定日期后，填写标题与故事说明，点击【创建并上传照片/视频】，可一次性选中多张照片和视频批量上传。系统将自动创建 `YYMMDD/` 文件夹并生成缩略图。
- **追加媒体**：在已有时刻卡片上点击【追加照片/视频】，继续扩充此日图集。
- **单张文件删除**：鼠标悬停在图集中的单张媒体上，点击红色垃圾桶图标，该文件将安全移至 `.trash/moment_media/YYMMDD/`。
- **解散时刻**：点击【解散时刻】，系统将整组文件夹完整移入 `.trash/moments/YYMMDD_YYYYMMDD_HHMMSS/`，并安全移除数据库关联。

### 5.3 回收站安全机制与清空
- **零冲突设计**：所有移入回收站的文件均附带秒级时间戳后缀，即使对同一天进行多次“上传-删除-再上传-再删除”，所有历史版本均在回收站完整留存，绝不相互覆盖。
- **扫描器完全隐身**：`.trash/` 属于隐藏目录，日常全量扫描与增量扫描会自动跳过，绝不会将废弃照片误扫回相册。
- **空间管理**：顶部实时显示回收站文件数量与占用空间，点击【彻底清空】并二次确认后，方可永久抹除废弃文件释放磁盘。

## 6. 系统运维与数据备份 (管理模式)

### 6.1 磁盘扫描与缺失排查
- **增量扫描**：日常添加照片后点击执行，仅比对变动项，秒级完成。
- **全量重新扫描**：全盘比对所有照片与目录，已编辑的心语、标签、合集数据**均有唯一日期记录保护，绝对不会丢失**。
- **缺失日期诊断与一键补录**：在扫描器面板中清晰罗列所有漏拍缺失的日期区间，点击每个日期右侧的 **“前往补录 &rarr;”** 按钮，系统将自动跳转至“档案内容维护”并自动锁定该缺失日期。

### 6.2 数据库快照与元数据备份
- **数据库快照**：点击“立即备份数据库”，系统将在 `data/backups/` 目录下生成带时间戳的 SQLite 备份文件。
- **元数据导出**：支持一键将全部照片档案、文字故事、标签、合集导出为标准结构化 JSON 归档文件，方便在任何外部环境做长期持久化存储。
