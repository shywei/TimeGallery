# Growing Up · 用户使用手册

Growing Up 是一套专为记录孩子成长而打造的私有化、轻量级、摄影杂志质感的数字成长相册与档案系统。系统在保证原始照片绝对安全只读的前提下，提供结构化日历、倒序时间河流、主题合集与时间回忆轮播等丰富功能。

---

## 1. 首次使用向导 (Setup Wizard)

首次运行应用并在浏览器打开 `http://127.0.0.1:8765` 时，系统将自动进入初次配置流程：
1. **输入孩子出生日期**（例如 `2024-01-01`）：用于系统精准自动计算每张历史照片拍摄时孩子的准确年龄（如 `2岁10个月3天`）。
2. **设置照片存储根目录**（例如 `D:\photos`）：指定存放 `yymmdd.jpg` 命名规范照片的本地目录。
3. 点击“完成初始化”，系统将自动触发初次全量索引，后台读取照片并生成流畅的 WebP 高性能缩略图与高清预览图。

## 2. 界面布局与丝滑导航体验

- **顶栏固定与独立滚动**：
  - 顶部导航栏常驻视口最顶层，不会随页面内容滚动，且完全不受内容滚动条出现或消失的影响，彻底消除视觉抖动。
- **页面后台常驻（Keep-Alive）**：
  - 首次访问页面时按需加载，访问过后页面在后台持久化保留状态；
  - 在各个标签页（首页、日历、时间轴、精选、合集）之间切换达到 **0 毫秒即时呈现**，无重复网络请求与白屏等待。

## 3. 核心功能浏览指南

### 3.1 首页 · 摄影杂志 (Home)
- **Today in Her Life（时光回忆轮播）**：
  - 核心主视觉画卷，展示过去的经典瞬间，下方提供“历史上的今天”、“去年此时”、“随机回忆”主题缩略卡片。
  - 支持 8 秒自动轮播，鼠标悬停时自动暂停，点击大图可直接展开查看。
- **Growth Statistics（成长统计）**：展示已归档有效照片总数、记录天数及当前实时年龄。
- **Recent Moments（近期瞬间）**：倒序展示最近有照片的 7 个自然日，快速预览近期日常。
- **Curated Highlights（成长精选）**：展示人工标记为精选的闪亮瞬间。

### 3.2 日历档案 (Calendar)
- **四种快速定位方式**：
  1. **快捷定位输入框**：支持直接输入标准日期 `2024-11-03` 或 6 位文件名 `241103`，回车瞬间跳转。
  2. **年月翻页箭头**：年月标题区域拥有固定宽度与等宽数字（`tabular-nums`），翻页时箭头按钮像素级原地锁定，连续点击不会发生移位与误触。
  3. **快捷按钮**：一键直达 `Today`（今天）、`This Week`（本周）、`This Month`（本月）。
- **三种时间维度视图**：
  - **日视图 (Day View)**：当天大图、完整拍摄日期、精确年龄、心语描述；无照片时呈现空白占位。
  - **周视图 (Week View)**：周一至周日 7 天矩阵，展示 `X / 7 days recorded`。
  - **月视图 (Month View)**：
    - **标准月历**：周一至周日标准 7 列，真实呈现每月的记录分布密度。
    - **月度照片墙**：瀑布流按日期升序排列当月所有照片，保持原始画幅比例。

### 3.3 时光河流 (Timeline)
- 按照时间倒序瀑布流展现全部成长记录，支持滚动加载更多。
- 顶部集成全库标签筛选气泡（展示每个标签的照片计数），点击标签即可单选过滤该标签下的所有精彩记录。

### 3.4 成长精选 (Highlights)
- 集中展示所有被标为“精选照片”的珍贵时刻。
- 无论是在“管理模式”还是“浏览模式”，都可以随时标记或取消精选。

### 3.5 主题合集 (Collections)
- **主题画册聚合**：自由创建如“第一次走路”、“海边夏令营”、“动物园游记”等专属主题合集。
- **合集内批量添加照片**：在合集详情页点击“添加照片”，可在弹窗中按日期或描述搜索全库照片，批量勾选快速加入。
- **合集移出**：在合集内悬停照片点击移除小图标，即可将照片从该合集中剔除（不影响原始档案）。

## 4. 照片详情与就地快捷编辑 (Photo Detail Modal)

点击任意照片缩略图即可呼出照片详情弹窗，弹窗支持**全面就地即点即改**，无需繁琐切换页面：

1. **标为精选**：
   - 顶部提供闪烁星星图标，点击一键在“精选”与“普通归档”之间切换。
2. **照片心语与故事（就地编辑）**：
   - 输入框始终可直接修改。当文字变动时，右上角灵动浮现 **“更新故事”** 与 **“还原”** 按钮。
   - 支持点击保存，或直接使用快捷键 **`Ctrl + Enter`** 快速提交。
3. **标签分类（类合集就地增删）**：
   - 当前照片已打的标签以 `#标签名` 气泡展示，点击标签右侧独立的 `×` 小按钮直接移除。
   - 点击 **`+ 添加标签`** 展开快捷面板，可直接输入新标签名回车添加，也可点击下方“推荐/已有标签”气泡一键加入。
   - 点击标签文字自身，弹窗将自动关闭并无缝跳转到“时光河流”页面，自动按该标签进行照片筛选。
4. **所属主题合集（就地归入）**：
   - 列出当前照片所在的所有合集，点击每个合集气泡的 `×` 可立即移出；
   - 点击“管理合集”可展开合集复选列表，勾选即可将当前照片快速归入对应合集。
5. **历史上的今天小图入口 (On This Day in Modal)**：
   - 弹窗右侧自动检索并展示往年同一月日的所有照片缩略图与拍摄年龄。
   - 点击任意历史小图，即可在当前弹窗中顺滑切换查看那一年同日的故事。
6. **双向日期穿梭与全屏沉浸浏览**：
   - 弹窗大图左右侧带有前后一日箭头，点击即可按时间连续查看上一张 / 下一张照片。
   - 点击右下角“全屏沉浸”进入黑底无干扰大图模式，支持键盘方向键（`←` / `→`）切图、`Esc` 退出、在沉浸模式下直接标记精选。

## 5. 后台维护与数据安全 (Management)

点击右上角切换至“管理模式”，即可进入维护面板：

### 5.1 照片扫描与重新建立
- **增量扫描**：仅读取新增的照片文件，耗时极短，日常添加照片后点击执行即可。
- **全量扫描与安全保证**：
  - 重新对照片目录进行全量深度比对。
  - **用户编辑数据绝对安全**：全量扫描根据唯一日期记录绑定，**不会丢失**已设置的照片故事、自定义标签、精选状态与合集关联。
  - **替换照片自动更新缓存**：若用户用更清晰的新照片替换了某一天的旧照片文件，全量扫描会通过文件修改时间校验自动重新生成对应的缩略图与高清预览图。
- **扫描规则与冲突规避**：
  - 严格识别 6 位纯数字文件名 `yymmdd.jpg`（如 `241103.jpg`）。
  - 若在不同子文件夹发现重复日期的冲突文件，系统严禁私自覆盖或删除，而是将其登记在“异常中心”的 `DATE_CONFLICT`（日期冲突）中，由管理员确认后再处理。

### 5.2 数据备份与恢复
- **数据库快照备份**：点击“立即备份数据库”，系统会自动在 `data/backups/` 目录下生成带时间戳的 SQLite 备份文件。
- **元数据导出**：支持一键将全部照片档案、文字故事、标签、合集导出为标准结构化 JSON 归档文件。
