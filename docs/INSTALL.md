# Growing Up · 安装与运行指南

## 1. 运行环境要求

- **操作系统**：Windows 10 / Windows 11
- **Python**：Python 3.12+ (本项目推荐并支持 Python 3.13)
- **Node.js**：Node.js 18+ (仅当需要重新编译前端静态资源时需要)
- **网络环境**：家庭私有局域网，不需要公网 IP，不依赖云服务。

---

## 2. 目录结构与隔离说明

- `backend/`：FastAPI 后端源码与虚拟环境 `.venv/`。
- `frontend/`：React 19 + TypeScript + Vite 前端工程。
- `data/`：应用独立运行数据目录（含 SQLite 数据库、缩略图、预览图缓存、日志、快照备份）。
- `scripts/`：Windows 批处理运维管理脚本。
- **用户原始照片目录**：由用户在首次向导（Setup Wizard）中任意指定，应用以**只读模式**读取。

---

## 3. 生产部署与局域网访问

### 3.1 默认本机访问
运行根目录 `run.bat` 后，服务默认监听 `127.0.0.1:8765`。
直接在电脑浏览器访问：`http://127.0.0.1:8765`。

### 3.2 家庭局域网多设备访问 (手机 / 平板)
若需在家中手机或平板上浏览照片：
1. 确保 Windows 防火墙允许 8765 端口入站连接（专用网络）。
2. 在 `scripts/start.bat` 中将监听地址改为 `0.0.0.0`：
   ```bat
   "%VENV_PYTHON%" -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8765
   ```
3. 查得 Windows 电脑的局域网 IP（例如 `192.168.1.100`），即可在手机浏览器打开：
   ```text
   http://192.168.1.100:8765
   ```

---

## 4. 故障排查

- **端口 8765 被占用**：运行 `scripts\stop.bat` 释放占用端口。
- **扫描未发现照片**：请检查照片主文件名是否严格为 6 位纯数字（如 `241103.jpg`），避免出现 `IMG_` 等前缀。
- **查看任务日志**：进入 `data/logs/` 目录下查看 `application.log` 与 `error.log`。
